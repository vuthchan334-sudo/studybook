01Cloud & Architecture · ហេដ្ឋារចនាសម្ព័ន្ធ និងប្រព័ន្ធ CloudScalability

Our distributed architecture ensures high availability and seamless horizontal scalability.

💡 Meaning: The cloud system can handle massive user growth without crashing or going offline. 🇰🇭 ខ្មែរ៖ ស្ថាបត្យកម្មប្រព័ន្ធចែករំលែករបស់យើង ធានាបាននូវភាពអាចដំណើរការបានខ្ពស់ (high availability) និងសមត្ថភាពពង្រីកទំហំប្រព័ន្ធ (scalability) ដោយរលូន។

02Cloud & Architecture · ហេដ្ឋារចនាសម្ព័ន្ធ និងប្រព័ន្ធ CloudBottleneck

Database queries were the primary bottleneck slowing down overall system response.

💡 Meaning: A single point of congestion that restricts the flow and slows the entire application. 🇰🇭 ខ្មែរ៖ ការទាញទិន្នន័យ (Database queries) គឺជាចំណុចកកស្ទះចម្បង (bottleneck) ដែលធ្វើឱ្យល្បឿនឆ្លើយតបនៃប្រព័ន្ធទាំងមូលធ្លាក់ចុះ។

03Codebase & Pipelines · វិស្វកម្មកូដ និងប្រព័ន្ធស្វ័យប្រវត្តRefactoring

Refactoring legacy code reduces technical debt and makes future feature rollout much faster.

💡 Meaning: Restructuring existing code without altering its external behavior to improve maintainability. 🇰🇭 ខ្មែរ៖ ការរៀបចំកូដចាស់ៗឡើងវិញ (Refactoring) ជួយកាត់បន្ថយបំណុលបច្ចេកទេស (technical debt) និងធ្វើឱ្យការបញ្ចេញមុខងារថ្មីៗកាន់តែរហ័ស។

04Codebase & Pipelines · វិស្វកម្មកូដ និងប្រព័ន្ធស្វ័យប្រវត្តPipeline

Every commit passes through an automated continuous integration and deployment pipeline.

💡 Meaning: Code is automatically tested, built, and shipped to production servers without manual human delay. 🇰🇭 ខ្មែរ៖ រាល់កូដដែលត្រូវបានបញ្ជូន (Commit) ត្រូវឆ្លងកាត់ប្រព័ន្ធស្វ័យប្រវត្តិនៃការត្រួតពិនិត្យ និងការបញ្ចេញឱ្យប្រើប្រាស់ (CI/CD pipeline)។

05Artificial Intelligence · បញ្ញាសិប្បនិម្មិត និងម៉ូឌែល AIPrompting

Effective prompt engineering allows large language models to generate precise structured outputs.

💡 Meaning: Crafting optimal input instructions so AI delivers exact, reliable, high-quality results. 🇰🇭 ខ្មែរ៖ ជំនាញក្នុងការរៀបចំសំណួរ និងបញ្ជា AI (prompt engineering) ជួយឱ្យម៉ូឌែលភាសាធំៗអាចបង្កើតលទ្ធផលដែលមានរចនាសម្ព័ន្ធ និងសុក្រឹតបំផុត។

06Artificial Intelligence · បញ្ញាសិប្បនិម្មិត និងម៉ូឌែល AIFine-tuning

We are fine-tuning an open-source model on proprietary domain-specific dataset.

💡 Meaning: Training a pre-trained base AI further using specialized company data for superior domain accuracy. 🇰🇭 ខ្មែរ៖ យើងកំពុងបង្វឹកកែសម្រួលបន្ថែម (fine-tuning) លើម៉ូឌែល AI កូដចំហ ដោយប្រើប្រាស់ទិន្នន័យឯកទេសផ្ទាល់ខ្លួនរបស់យើង។

07Performance & Hardware · ល្បឿន និងប្រសិទ្ធភាពដំណើរការLatency

By deploying servers closer to users, we achieved ultra-low latency and higher throughput.

💡 Meaning: Minimizing delay (latency) and maximizing the volume of processed data per second (throughput). 🇰🇭 ខ្មែរ៖ តាមរយៈការដាក់ម៉ាស៊ីនបម្រើ (Servers) នៅក្បែរអ្នកប្រើប្រាស់ យើងសម្រេចបាននូវភាពយឺតយ៉ាវទាបបំផុត (ultra-low latency) និងល្បឿនដំណើរការទិន្នន័យខ្ពស់។

08Performance & Hardware · ល្បឿន និងប្រសិទ្ធភាពដំណើរការEdge computing

Processing inference directly on edge devices protects privacy and cuts cloud hosting expenses.

💡 Meaning: Running AI computation locally on phones or edge hardware rather than sending private data to remote cloud servers. 🇰🇭 ខ្មែរ៖ ការដំណើរការគណនា AI ដោយផ្ទាល់នៅលើឧបករណ៍ចុងក្រោយ (Edge computing) ជួយការពារឯកជនភាព និងកាត់បន្ថយការចំណាយលើសេវា Cloud។

Tech Misconceptions · ការយល់ច្រឡំលើពាក្យបច្ចេកវិទ្យា

Latency is the time delay for a single data packet to travel, whereas throughput is the total volume of data transferred over time.

💡 English: Think of latency as speed of a car, and throughput as the number of lanes on a highway. 🇰🇭 ខ្មែរ៖ Latency គឺជាពេលវេលាយឺតយ៉ាវក្នុងការធ្វើដំណើរនៃទិន្នន័យមួយកញ្ចប់ ចំណែកឯ Throughput គឺជាបរិមាណទិន្នន័យសរុបដែលអាចឆ្លងកាត់បានក្នុងមួយវិនាទី។

Confusing latency and throughput leads to buying the wrong server infrastructure.

System Design Questions · សំណួររចនាប្រព័ន្ធ

It is the future cost of rework caused by choosing an easy quick fix now instead of a well-designed sustainable solution.

💡 English: Like financial debt, tech debt accrues interest and makes all future development slower and riskier. 🇰🇭 ខ្មែរ៖ វាគឺជាការចំណាយពេលវេលា និងថវិកាក្នុងការជួសជុលនាពេលអនាគត ដែលបណ្តាលមកពីការជ្រើសរើសវិធីដោះស្រាយកាត់ៗនៅពេលនេះ ជាជាងការរចនាកូដឱ្យបានត្រឹមត្រូវ។

Technical Clarifications · ឃ្លាសួរនាំក្នុងការងារបច្ចេកវិទ្យា

Is this service stateful or completely stateless?💡 English: Inquiring whether the application retains session data across requests · 🇰🇭 តើសេវាកម្មនេះរក្សាទុកទិន្នន័យ Session (Stateful) ឬគ្មានការរក្សាទុក (Stateless)?

Cloud & Infrastructure · ប្រព័ន្ធ Cloud

  • Scalability💡 The capacity to handle growing amounts of work by adding resources · 🇰🇭 សមត្ថភាពក្នុងការពង្រីកទំហំប្រព័ន្ធ
  • High availability💡 Systems engineered to remain continuously operational without interruption · 🇰🇭 ភាពអាចដំណើរការបានខ្ពស់ មិនងាយគាំង
  • Bottleneck💡 A constraint point that congests and slows down overall throughput · 🇰🇭 ចំណុចកកស្ទះដែលបន្ថយល្បឿន
  • Distributed system💡 Software whose components reside on multiple networked computers · 🇰🇭 ប្រព័ន្ធកុំព្យូទ័រដែលបែងចែកលើបណ្តាញច្រើន

Engineering Practices · វិស្វកម្មផ្នែកទន់

  • Refactoring💡 Restructuring code to improve internal design without changing behavior · 🇰🇭 ការរៀបចំកូដឡើងវិញឱ្យស្អាត និងមានរបៀប
  • Technical debt💡 Implied cost of additional future rework caused by expedient shortcuts · 🇰🇭 បំណុលបច្ចេកទេស ពីការសរសេរកូដកាត់ៗ
  • Deployment pipeline💡 Automated sequence of stages for compiling, testing, and shipping code · 🇰🇭 ប្រព័ន្ធស្វ័យប្រវត្តិនៃការបញ្ចេញកូដ
  • Rollback💡 An operation that restores a database or software to a previous clean state · 🇰🇭 ការទាញយកកំណែកូដមុនមកប្រើវិញពេលមានបញ្ហា

Artificial Intelligence · បញ្ញាសិប្បនិម្មិត

  • Prompt engineering💡 Structuring instructions to guide generative AI models toward optimal output · 🇰🇭 ជំនាញរៀបចំសំណួរ និងបញ្ជា AI
  • Fine-tuning💡 Adapting a pre-trained model to specific tasks using custom training data · 🇰🇭 ការបង្វឹកកែសម្រួល AI បន្ថែមលើទិន្នន័យជាក់លាក់
  • Inference💡 The process of running live data through a trained model to make predictions · 🇰🇭 ដំណើរការគណនាទស្សន៍ទាយរបស់ AI ជាក់ស្តែង
  • Hallucination💡 When an AI model generates factually incorrect or fabricated information confidently · 🇰🇭 ការឆ្លើយខុស ឬការស្រមើស្រមៃខុសការពិតរបស់ AI

Performance & Hardware · ល្បឿន និងសមត្ថភាព

  • Latency💡 The time delay between a request initiation and its execution · 🇰🇭 រយៈពេលយឺតយ៉ាវនៃការឆ្លើយតប
  • Throughput💡 The amount of material or data processed through a system in a given time · 🇰🇭 បរិមាណទិន្នន័យដែលដំណើរការបានក្នុងមួយឯកតាពេល
  • Edge computing💡 Computation and data storage performed near the physical source of data · 🇰🇭 ការគណនាទិន្នន័យនៅក្បែរប្រភពឧបករណ៍ផ្ទាល់
  • Paradigm shift💡 A fundamental change in approach, methodology, or underlying assumptions · 🇰🇭 ការផ្លាស់ប្តូរផ្នត់គំនិត ឬបច្ចេកវិទ្យាទាំងស្រុង

Tech Misconceptions · ការយល់ច្រឡំលើពាក្យបច្ចេកវិទ្យា

Q. What is the real difference between latency and throughput?

Q. សំណួរ៖ តើអ្វីជាភាពខុសគ្នាពិតប្រាកដរវាង Latency និង Throughput?

A. Latency is the time delay for a single data packet to travel, whereas throughput is the total volume of data transferred over time.

A. 💡 English: Think of latency as speed of a car, and throughput as the number of lanes on a highway. 🇰🇭 ខ្មែរ៖ Latency គឺជាពេលវេលាយឺតយ៉ាវក្នុងការធ្វើដំណើរនៃទិន្នន័យមួយកញ្ចប់ ចំណែកឯ Throughput គឺជាបរិមាណទិន្នន័យសរុបដែលអាចឆ្លងកាត់បានក្នុងមួយវិនាទី។

System Design Questions · សំណួររចនាប្រព័ន្ធ

Q. What does technical debt mean to a software engineering team?

Q. សំណួរ៖ តើ 'Technical Debt' (បំណុលបច្ចេកទេស) មានន័យដូចម្តេចចំពោះក្រុមវិស្វករ?

A. It is the future cost of rework caused by choosing an easy quick fix now instead of a well-designed sustainable solution.

A. 💡 English: Like financial debt, tech debt accrues interest and makes all future development slower and riskier. 🇰🇭 ខ្មែរ៖ វាគឺជាការចំណាយពេលវេលា និងថវិកាក្នុងការជួសជុលនាពេលអនាគត ដែលបណ្តាលមកពីការជ្រើសរើសវិធីដោះស្រាយកាត់ៗនៅពេលនេះ ជាជាងការរចនាកូដឱ្យបានត្រឹមត្រូវ។
